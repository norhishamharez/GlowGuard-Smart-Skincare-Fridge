# GlowGuard: Smart Skincare Fridge

## Project Overview
GlowGuard is an IoT-based Smart Skincare Fridge that helps users store skincare products under optimal conditions.

## Features
- Temperature monitoring
- Humidity monitoring
- Light exposure monitoring
- Door open detection
- Expiry date tracking
- Active ingredient tracking
- Mobile notifications

## Hardware
- ESP32
- DHT11
- LDR
- Magnetic Reed Switch
- Buzzer
- LED
- Servo Motor

## IoT Platform
- Blynk
